# Information Security Policy

Owner: Security Engineering. Classification: internal.

## Passwords and MFA

All employees must enable multi-factor authentication (MFA) on their SSO account. Passwords must be
at least 14 characters. Hardware security keys are required for production access.

## Reporting incidents

Report suspected security incidents immediately to security@example.com or via the #sec-incident
channel. The on-call security engineer acknowledges within **15 minutes**, 24/7.

## Laptop encryption

Company laptops must use full-disk encryption (FileVault or BitLocker). Lost devices must be reported
within 24 hours so they can be remotely wiped.

## Data classification

Data is classified as public, internal, confidential or restricted. Restricted data (for example
customer PII and payment data) may only be stored in approved systems listed in the data register.
